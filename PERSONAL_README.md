### 🏠 RentManager
A property and rental management SaaS built for the Kenyan market, with M-Pesa (STK Push) rent collection.

**Tech Stack:** Java 21, Spring Boot 3, PostgreSQL, Next.js 16, React 19, React Native
**Highlights:**
- Modular monolith with 20+ modules, avoiding unnecessary microservices complexity
- Tenant isolation from verified Clerk JWT, enforced at repository level
- Append-only financial ledger enforced by PostgreSQL triggers
- Idempotent M-Pesa STK Push with 3-minute window deduplication
- Pessimistic locking on disbursements to prevent double payouts
- 1,500+ automated backend tests using Testcontainers
