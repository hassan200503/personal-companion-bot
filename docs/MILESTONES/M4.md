# Milestone M4: Provider Gateway

**Status:** COMPLETE  
**Completed:** 2026-10-26  
**Commits:** 1912dc2 (contracts + mock), + this commit (router, catalog, onboarding)

## Objective

Build the provider gateway: router with quota ledger, circuit breakers, and fallback; provider catalog with OpenRouter/Groq/Together/Fireworks; and post-key onboarding pipeline (validateKey/listModels/probe/seedQuotas). Exposed via `providers/index.ts`.

## Exit Criteria

✅ Router selects healthy providers by priority  
✅ Fallback works on provider failure  
✅ Circuit breaker opens after threshold failures  
✅ Quota ledger tracks usage and rate limits  
✅ Catalog exposes providers with onboarding metadata  
✅ Key format validation works  
✅ Onboarding pipeline validates keys, lists models, probes, seeds quotas  
✅ All provider tests pass (65 tests)

## What Was Implemented

### 1. Provider Contracts (`contracts.ts`)
- `ChatProvider` interface, `ProviderError` with error taxonomy
- Request/response types, capabilities, health status
- `ProviderCatalogEntry`, `ProviderFactory`

### 2. MockProvider (`mock-provider.ts`)
- Scriptable latency, errors, rate limits, responses
- 18 tests

### 3. Provider Router (`router.ts`)
- `QuotaLedger`: tracks prompt/completion tokens, request count, rate limits
- `CircuitBreaker`: closed/open/half-open with configurable thresholds
- `ProviderRouter`: register/unregister/enable, selectProvider, complete, stream, fallback, getStatus, reset
- 27 tests (6 QuotaLedger + 5 CircuitBreaker + 16 ProviderRouter)

### 4. Provider Catalog (`catalog.ts`)
- 4 providers: OpenRouter, Groq, Together AI, Fireworks AI
- OpenAI-compatible provider factory with fetch-based complete/stream/healthCheck
- Helpers: getProviderCatalog, getProviderEntry, getProvidersByMode, getProviderModels, validateKeyFormat
- 11 tests

### 5. Onboarding Pipeline (`onboarding.ts`)
- `DefaultOnboardingPipeline`: validateKey, listModels, probe, seedQuotas
- Live validation via health check, model listing with catalog fallback
- Quota seeding with per-provider defaults
- 9 tests

### 6. Index Exports (`index.ts`)
- Re-exports contracts, mock-provider, router, catalog, onboarding
