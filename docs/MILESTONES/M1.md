## Test evidence

- `packages/core/src/config.test.ts`: default config, minimal-config defaults, explicit values, unknown schema version rejection, invalid theme rejection.
- `packages/core/src/logger.test.ts`: nested sensitive-key redaction, circular references, error serialisation, level filtering and log redaction.
- No end-to-end automation ran. The manual launch proved that the main process creates a window and loads the built renderer, but did not exercise the IPC button.

## Security posture at M1

- Renderer runs with `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`, `webSecurity: true` and a restrictive CSP.
- The preload exposes only `getInfo`; main validates the sender and a per-window random session token before responding.
- New windows are denied and navigation is blocked.
- The logger redacts sensitive key names, but does not yet scan free-text messages or error strings for secret patterns. This is a known limitation for M2/M11 hardening.
- The CSP includes `ws://localhost:5173` and `http://localhost:5173` to support the Vite dev server. Production runs from `file://` and makes no network requests at M1.
- No credentials, storage, providers or network calls exist yet.

## Required configuration

- Node `>=22.5.0` and npm.
- Electron 45.0.0 is pinned exactly for electron-builder.
- No environment variables, API keys or accounts are required.
- `VITE_DEV_SERVER_URL` is optional and only for development.

## Known defects and gaps

- The installer is unsigned and uses the default Electron icon. SmartScreen behaviour was not tested by installing it.
- The NSIS package was built but not installed. Installed size, uninstall behaviour and first-run behaviour are unverified.
- CI is written but has not run on GitHub; the repository has not been pushed.
- There is no Playwright/Electron E2E test yet. Playwright's Electron support is experimental.
- The main-process bundle is 743.4 KB because Zod and the core package are bundled; source maps are included in the package.
- Runtime memory use was not measured.
- No tray, startup, storage, provider, memory or tool code exists yet.
